# japanese-corpus/ — 和文原稿コーパス

このフォルダは **Step 5 の和文ライティングスタイル抽出** で使う和文原稿の入力先です。

---

## サブフォルダ構成

| サブフォルダ | 入れる原稿の種類 |
|---|---|
| `01_papers/` | 学術論文（症例報告・原著の和文 PDF/docx/md/txt） |
| `02_reviews/` | 総説・教科書原稿 |
| `03_blog/` | note・ブログ記事 |
| `04_sns/` | X投稿、Instagram台本など短文 |

---

## 投入のしかた

### 推奨

- 各ジャンルに **最低1本ずつ** あると再現精度が上がります
- ファイル形式は **PDF / docx / md / txt** に対応（Cowork が自動で読み込みます）
- ファイル名に日付（例: `2024-03_review-AI内視鏡.docx`）を入れておくと、最近の文体傾向を分析しやすくなります

### 任意

- サンプル数が多いほど精度が上がりますが、各ジャンル 1〜3 本でも十分実用的です
- 同じ内容のドラフト違い（投稿前 / 投稿後）を両方入れる必要はありません（投稿後の最終版を優先）

### 投入したくない／投入できない場合

- 該当ジャンルにサンプルが無くても問題ありません。Step 5 では「サンプル無し → このジャンルの再現精度低」と persona.md に明示します
- 例えば SNS 運用していない方は `04_sns/` を空のままにして OK

---

## プライバシー・セキュリティ

- 患者情報・未公開研究データを含む原稿は **このフォルダに入れない** でください（Cowork が読み込み、分析過程でAI処理されます）
- 公開済み論文・公開済みブログ・公開済みSNS など、**第三者に見られても問題ない原稿のみ** を入れてください
- 個人情報・症例情報を含む原稿を分析したい場合は、事前に匿名化してから投入してください

---

## このフォルダの中身は分析対象

Step 5 開始時、Cowork は以下を自動実行します。

```
Glob: japanese-corpus/01_papers/*
Glob: japanese-corpus/02_reviews/*
Glob: japanese-corpus/03_blog/*
Glob: japanese-corpus/04_sns/*
```

その後、各ファイルを `Read` で読み込み、`05_和文ライティングスタイル抽出.md` の手順に従って分析します。

分析結果は `outputs/writing-style-ja.md` に保存され、Step 6 で persona.md に統合されます。
