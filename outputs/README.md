## 試作物（style-test-*.md）の取り扱い

すべての試作物の冒頭には **「AI試作」ヘッダー** が明示されます。

```
---
⚠️ これは {対象者名} のペルソナを使った AI 試作です。
本人承認なしに外部送信・公開しないでください。
作成日: 2026-04-29 / persona.md バージョン: vX.X
---
```

これは CLAUDE.md ルール#4（非ゴール：本人未承認のなりすまし禁止）に基づきます。試作物を外部に展開する前に、必ず対象者本人の承認を得てください。

## persona.md との関係

中間成果物3点（`publications.md` / `writing-style-en.md` / `writing-style-ja.md`）は、Step 6 で `persona.md` に統合されます。

統合後も中間成果物は残ります。理由:
- persona.md は **要約版**（運用時に読みやすい形）
- 中間成果物は **詳細版・根拠サンプル付き**（後で「なぜこの特徴を抽出したか」を追跡できる）

半年〜1年後にアップデートする際、中間成果物を残しておくと差分比較がしやすくなります。
